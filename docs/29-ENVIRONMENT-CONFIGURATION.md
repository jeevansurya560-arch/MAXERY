## 1. Master Environment Variable Matrix

| Variable Name | Required | Default Development Value | Production Description & Constraints |
|---|---|---|---|
| `NODE_ENV` | Yes | `development` | Runtime mode: `development`, `test`, `production`. |
| `DATABASE_URL` | Yes | `postgresql://maxery_user:maxery_secure_pass@localhost:5432/maxery_dev?schema=public` | PostgreSQL connection string with SSL mode enabled in production. |
| `API_PORT` | Yes | `4000` | Local port for dedicated Fastify API server. |
| `API_HOST` | Yes | `0.0.0.0` | Host binding for Fastify HTTP listener. |
| `JWT_SECRET` | Yes | `maxery_dev_jwt_secret_key_minimum_32_characters_for_security_checks` | Secret key for signing JWTs. Must be minimum 256 bits (32 chars) generated by cryptographic random source. |
| `CORS_ORIGIN` | Yes | `http://localhost:3000` | Allowed CORS origins for Next.js web application. |
| `REDIS_URL` | No | `redis://localhost:6379` | Optional connection string for Redis rate limiting and pub/sub. |
| `WEB_PORT` | Yes | `3000` | Local port for Next.js web frontend. |
| `NEXT_PUBLIC_API_URL` | Yes | `http://localhost:4000/api/v1` | Public API base URL accessed by client browser. |
| `NEXT_PUBLIC_SOCKET_URL` | Yes | `http://localhost:4000` | Public WebSocket URL accessed by client browser. |

## 2. Security Checklist for Production Deployments

- [ ] All `.env` files are added to `.gitignore` and verified absent from Git commit history.
- [ ] `JWT_SECRET` is rotated to a cryptographically secure 64-character random string injected via KMS.
- [ ] `DATABASE_URL` uses high-availability managed database endpoints with mandatory TLS (`sslmode=require`).
- [ ] CORS origins strictly match the production domain (e.g., `https://maxery.org.in`).
- [ ] Database user credentials adhere to the principle of least privilege (application user does not have `DROP TABLE` permissions).
